# GEMO3D Demo 與方法比較展示規劃（2026-11-18）

> 素材的優先順序、交付格式與呈現設計已整理於 `docs/DEMO_ASSETS.md`（最優先）。

參考學術專案頁的呈現方式：Teaser 影片 → 方法總覽 → 輸入／輸出 Demo → 前後對照滑桿 → 與其他方法同畫面比較 → 失敗案例。
目標：評審 30 秒內看懂「輸入一張影像 → 得到 3D 車輛框與距離」，且看得出補償前後、與其他方法的差異。

> 規則：所有數字須來自實驗輸出檔（`results/`）；未量測者在頁面與簡報標「—」，不得以估計值代替。

## 二、實驗室工作清單（依優先順序）
1. **D4 比較影片**：在同一 CARLA 序列（建議 300 幀）跑 MonoDETR / MonoDGP / MonoAMNet，輸出 `results/demo/baselines/<method>/<frame>.txt`。
2. **D3 前後對照**：選 6 張影像（近 / 中 / 遠 × 正面 / 斜側），輸出 `results/demo/compare/<id>_raw.png`、`<id>_corr.png`、`<id>_bev.png`。
3. **D1 Teaser**：`render_sequence_video.py` 加 BEV 面板與 GT，輸出 `results/demo/teaser.mp4`。
4. **D2 中間輸出**：每張代表影像輸出 2D 框、Z_raw、r̂、Z_corr 數值（JSON）與疊圖。
5. **D7 失敗案例**：從 165 個共同樣本中挑誤差最大的 5 筆，附原因。
6. **D6 真實序列**：完成 N10 後再加入。

## 三、檔案規格
- 影片：1920×1080、30 fps、H.264（`-crf 23 -pix_fmt yuv420p`），單檔 ≤ 25 MB（GitHub 單檔上限 100 MB，網頁載入考量取 25 MB）；附一張首幀 JPG 作封面。
- 對照圖：同組 PNG 尺寸完全相同，寬 1600 px。
- 命名：`<demo編號>_<內容>_<日期>.mp4`，例如 `D4_method_compare_1120.mp4`。
- 上傳位置：本 repo `results/demo/`；網頁用的壓縮版另放 GitHub Pages `assets/`；原始大檔放雲端並在 `docs/MATERIALS_NEEDED.md` 記錄連結。

|---|---|---|

| JanusMesh | Teaser＋依類別分組的結果影片牆 | 依情境分組的結果影片牆（跟車／超車／對向／路口…） |

## 七、需要跑的 CARLA 連續序列清單（給實驗室）

每段：前視相機（與論文相同內參、相機高 1.65 m）、10–20 秒、30 fps；需同時輸出 GT（KITTI 格式）。
每段產出三聯畫面：**左** 前視影像＋3D 框（藍：GEMO3D、橘虛線：GT）｜**中** BEV 俯視（含 GT）｜**右** 深度誤差隨時間曲線；另產出同段的 MonoDETR（2023）／MonoDGP（2025）／MonoAMNet（2025）2×2 同步比較版。

| 編號 | 情境 | 設定重點 | 要看出什麼 | 優先 |
|---|---|---|---|---|
| S1 | 同向跟車 | 前車 5→35 m 加速遠離、再減速接近 | 深度隨距離變化仍穩定（對應分區間圖） | 高 |
| S2 | 被超車 | 左後方車輛超越本車並切入前方 | 觀測角快速變化（側面→背面）時補償效果 | 高 |
| S3 | 本車超車 | 本車由右車道超越前車 | 同上，反方向角度變化 | 中 |
| S4 | 對向來車 | 對向車道車輛由遠而近、擦身而過 | 正面視角、近距離大角度 | 高 |
| S5 | 路口轉彎 | 前方車輛左轉／右轉通過路口 | 側面視角（觀測角 90° 附近）最容易偏差之處 | 高 |
| S6 | 前車切入 | 鄰車道車輛突然切入（cut-in） | ADAS 碰撞預警情境 | 中 |
| S7 | 多車同時 | 3 台以上不同車型（Compact／Sedan／SUV） | 車型分類＋多目標 | 中 |
| S8 | 彎道／坡道 | 道路彎曲、上下坡 | 限制條件（道路坡度）展示，可作失敗案例 | 低 |
| S9 | 相機俯仰角改變 | 鏡頭上抬／下壓（對應附錄 Pitch 實驗） | 敏感度與校正前後 | 低 |
| S10 | 夜間／雨天 | 同 S1 改天候 | 魯棒性；結果不佳也如實呈現 | 低 |
| R1 | 真實道路序列 | KITTI 連續序列（NEXT_EXPERIMENTS N10） | 真實資料泛化 | 待量測 |

方法動畫（不需新實驗）：M1 單車 0–360° 旋轉＋h2D／h3D,proj 比例即時曲線；M2 針孔相似三角形動畫；M3 Rank-1 曲面分解成三條曲線的動畫。
