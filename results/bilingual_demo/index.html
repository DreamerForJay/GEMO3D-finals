朝向角影片怎麼看？ / Reading the yaw clips

① 黃點是決定框高的上下支撐點；紅框是投影外接框；綠線是理想高度。藍色車輛外接盒只旋轉，距離固定10m。淡藍線標車頭方向，左上角方向盤顯示yaw。② 綠色真實距離不動；紅色針孔估計隨框高變動。兩片使用相同角度與資料，可以分開講解原因與結果。

Yellow dots mark the projected height extrema; red is the projected bounding rectangle, green the ideal height. A cyan nose marker and yaw dial reveal rotation. Clip 2 compares fixed true depth with pinhole depth. Both clips share the same sweep.

幾何示意 / Geometry illustration：這是矩形車輛外接盒的精確透視投影，不是實測旋轉影片、偵測器輸出或模型準確率。h_ideal = fy H / Z，r = h2D / h_ideal，Z_pinhole = Z / r。原訓練h3D,proj定義仍待原始建模腳本核對。影像框支撐點在物體輪廓上的位置可切換；不表示所有真實車型或任意角度都有相同偏差方向。

實測影片圖例與數據 / Recorded-data legend

綠虛線＝GT，紅實線＝預測。3D中心誤差越低越好；BEV重疊率越高越好。黃色大字僅強調數值，不代表新物件。Full＝完整F流程，貼合＝tightfit。199來源影格完整保留，漏檢標未配對；影片30fps為離線播放，非推論速度。RGB配對以image ID為準，原metadata的三處重複仍保留。

Green dashed = GT; red solid = prediction. Lower 3D center error / higher BEV IoU is better. Yellow highlights numbers only. Unmatched observations are not zero errors. These are re-rendered controlled predictions, not new inference. Image-ID pairing does not establish strict sensor synchronization.
